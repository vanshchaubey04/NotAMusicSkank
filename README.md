# AirBeat (NotAMusicSkank)

A gesture-controlled music maker for macOS using the webcam.

- **Right Hand**: Air drumming (two-finger downward hits trigger drum sounds, controls BPM cadence)
- **Left Hand**: Gesture-driven GUI to pick musical Key, Scale, and Backing Track

See [PROJECT.md](PROJECT.md) for full architecture and development details.

## 🚀 Quick Start

1. **Activate Python 3.11 virtual environment:**
   ```bash
   source venv/bin/activate
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the camera test / app:**
   ```bash
   python main.py
   ```
